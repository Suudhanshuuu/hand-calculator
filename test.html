Hand Number Counter - Test Page

This page helps verify that all components are working correctly.

✅ Quick Start

To use the app:

  1. Option 1 (Recommended): Run python server.py in this directory, then open http://localhost:8000
  2. Option 2: Open index.html directly in your browser (may have CORS issues with model loading)
  3. Option 3: Use any simple HTTP server like python -m http.server 8000

🔧 Manual Test

After opening the app, check these features:

  • ✓ Camera starts when clicking "Start Camera"
  • ✓ Hand landmarks appear on your hand
  • ✓ Finger count updates in real-time
  • ✓ Numbers are added to the total
  • ✓ History shows previous numbers
  • ✓ "Reset" button clears the counter

📝 Troubleshooting

If it doesn't work:

  • Make sure you're using Chrome or Firefox (best supported)
  • Allow camera permissions when prompted
  • Ensure good lighting on your hand
  • Make sure your hand is clearly visible to the camera
  • Try refreshing the page if the model fails to load

🎯 Test Your Hand

Try these hand positions:

  • ✌️ Show 2 fingers - should detect 2
  • 👋 Show 5 fingers - should detect 5
  • 🤟 Show 0 fingers (fist) - should detect 0
  • 👆 Show 1 finger - should detect 1

The app should add each detected number to the running total!
